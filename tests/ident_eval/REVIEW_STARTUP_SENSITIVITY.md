## 2. 高危样本的根因：校准后残余零偏推动转子

- 消融：去掉 ±0.5%FS 残余零偏，h129/h252/h091 的 SwpL 从 18–28% 降到 2–6%；只保留零偏时为 17–22%。
- 转角跟踪（`SIM_DIAG_TIER=1`，`TRACE` 行）：死区阶梯末档只有 0.05 A，与零偏同量级，转子在该段开始漂移；电流回零后，实际电流 = −零偏，形成固定方向的小电流矢量，几乎无阻尼的风机转子绕新平衡点大幅摆动（>100°），交流阻抗就是在这种状态下测出来的。
- 漏检原因：运动监测只看正交轴子窗均值的峰峰值。转子转过 δ 后反电势按 cosδ / sinδ 分到两轴，δ≈90° 时正交轴失明；0.5·f0 段（seg 6、11）也不在监测范围内。
- 试验过的修正：
  - 双轴（注入轴 + 正交轴）矢量峰峰值监测：开发集高危静默失败 2→0、漏拦坏样本 9→4、SwpL p95 6.40%→5.22%，但 FP 2→8（2.7%），且对位阻尼网格 J0.1/J0.3×ψ2 两格被误拦（低惯量高磁链转子的 f0 振动，已被摆动系数 k 正确补偿）。
  - q 轴零偏置段加 d 轴保持电流：p95 降到 4.4%，但引入新的失败（h135：偏置改变电流过零，与死区补偿相互作用，L0 抬高 11%）。
  - **两者都未采用**，理由见第 3 节。

## 3. 起动敏感度：哪些参数真正影响"进 I/F 和闭环"

方法：仿真对象取配置标称值为真值，只缩放控制器 `gParam` 的单项（`SIM_PK_RS / L / LD / PSI / ACC / DT / LSPER / LSKNEE / LSMAX`），`IDENT_MODE_RUN` 起动 8 s。
判据：无故障、进入 Spin、进入后不退出、结束时转向正确且 |rpm| > 30% 指令。

| 参数（×倍数） | fan | mid48 | sm120 | vac48 | ipm2 |
|---|---|---|---|---|---|

（表中为通过的倍数范围；失败大多为堵转故障 0x10。）

- 当前辨识精度量级的组合误差（Rs ±9%、L ±8%、死区 ±15%）：只有 vac48 在 Rs、死区都**偏大**时失败，偏小时通过。
- 自动模式（静止 → 运行测量 → 运行）下，运行测量的 ψ 误差在 fan/mid48/ipm2 上 ≤0.3%，加速度系数正确跟随惯量变化。
- **初始转角扫描（参数完全正确、不做辨识）**：vac48 30/36、vac16 33/36、fan 35/36，失败角集中在 290°–330°，其余 7 类 36/36。vac48 自动模式在标称电机上也失败，就是因为静止测量后转子停在了失败角附近，与辨识参数无关（逐项代入辨识结果均可起动）。

## 4. 对"必须 / 画蛇添足"的判断（仅针对"能起动"这个目标）

**必须保留，且值得投入：**
- R/L 粗测（电流环 PI 的起点）。
- 死区阶梯测 Rs 与死区，以及阶梯期间的静止检测：低阻电机（vac 类）上 Rs、死区偏大 15% 就起不来，这是辨识里最影响起动的部分。
- 运行测量的 ψ 与加速度系数：mid48/vac48 的 ψ 只能容忍 ±15%，vac48 的加速度系数偏大 15% 即失败。但协议 v2.1 的盲测全部为 `IDENT_MODE_STATIC`，**从未验收过这两个量**。
- L0（单一电感值）：需要，但容忍度宽（多数 0.5–2 倍），单频测量足够。

**对起动目标而言属于过度设计（不影响起动，但各自带来误拦或静默失败的风险）：**
- q 轴 5 档饱和扫幅、3 次谐波描述函数修正、`SAT_FIT` 网格拟合、`lsMaxA` 1.5 倍外推、`AMP_ORDER` 降级、`lTop>1.10·L0` 护栏、深饱和降级：全部服务于 L(i) 曲线，而 L(i) 在所有测试中都不影响起动。协议主指标 SwpL 衡量的正是它。
- 交流段转子运动监测中，专门保护饱和档精度的部分（以及本次试验的双轴检测）：保护的是不影响起动的量，却会误拦好电机。
- Ld/Lq 分离：凸极比误差在所有测试中都不影响起动（IPD 角度检测另当别论）。
- 摆动系数 k 的两频点估计、多频延迟校准：主要用于 L 精度，对起动的意义有限。

**比任何辨识门限都优先的事：** 起动流程在 290°–330° 初始角附近的失败（vac 类、fan）。即使辨识完全正确，这个问题也会让电机起不来。

## 5. 建议的验收口径（若目标改为"能起动"）

1. 新增主指标"起动成功率"：随机电机 × 随机初始角，跑 `IDENT_MODE_AUTO` 全流程，判据同第 3 节。
2. 运行测量的 ψ / 加速度系数纳入盲测（目前完全空白）。
3. Rs、死区按"宁低勿高"验收（vac 类偏高失败、偏低通过）。
4. SwpL 降为参考指标，不再作为阻断依据。
