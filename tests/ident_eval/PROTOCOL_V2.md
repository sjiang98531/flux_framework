# 参数辨识冻结评估与消融协议（Frozen Protocol v2.0）

> **历史记录（2026-11-25 注）**：本文针对 `05337d7` 之前的辨识实现（2-DOF 交流注入、`acFit` 饱和拟合、阻断门控），这些代码已删除，文中函数、行号与验收结论不适用于当前代码。当前实现与验证方式见仓库根目录 `REVIEW_STATUS.md`。

> 本协议与测试代码/种子在盲测之前修订并冻结提交，取代 v1.0。修订目的：
> 1. 区分辨识实际扫幅区间的算法拟合精度（`SwpL%`）与超出该区间后的运行期外推覆盖缺口（`RunL%`）。
> 2. 避免把 `lsMaxA` 在扫幅之上的强制钳平造成的模型覆盖限制，事后误算为算法失败。
> 3. 在加入传感器组合扰动与坏电机门控集后，先写死盲测验收线。

---

## 1. 不变的基础定义

- **运行期模型**：与 `flux_obs.c:lsEff` / `param.c:Param_LqAt` 逐公式一致，包含运行期实际生效的 `gParam.lqH / lsKneeA / lsPerA / lsMaxA`。
- **阻断位**：`blk = bool(warn & IDENT_WARN_AUTO_BLOCKED)`。
- **固定真值模型**：
  - 线性拐点饱和：`L0 * max(0.5, 1 - ksat*(i-i0sat))`；
  - 渐加速平滑饱和（`SIM_SMOOTH_SAT_I0`）：使用 `plant.c` 增量电感的精确积分，即割线真值 `L0*(0.5 + 0.5/(1+(i/I0)^2))`。
- **物理量报告**：`Rs%`、`Ld%`、`Lq%`、`knee/perA`、所有 `warn` 位、`s_acIpkLim` 触顶/中止恢复、定位末端角度与运行期 `ipk` 仍按 v1 记录。

## 2. 两个独立指标与职责

### 2.1 主指标 `SwpL%`（辨识区间精度）
- 在固定 $I_{\text{swp}} = 2.5\cdot\text{IDENT\_I\_SCALE}$ 上均匀采样 200 点，采用运行期含 `lsMaxA` 钳位模型评估最大相对误差。
- 用于回答：“在实际施加过激励的电流范围内，辨识曲线是否准确”。

### 2.2 运行期指标 `RunL%`（过载外推覆盖）
- 在固定 $I_{\text{run}} = \min(\text{SPD\_PI\_LIMIT}, I_{\text{MAX}})$ 上评估最大相对误差，**单独报告 p50/p95/max，不混同为主算法指标**。
- 同时报告 `I_swp / I_run` 覆盖率及“超过扫幅上限后 `RunL` 增量”，避免把外推覆盖缺口误记为区间内拟合失败。
- 在 `db61f05` 的 `lsMaxA=1.0x` 钳平策略下，运行上限高于扫幅上限的电机会出现真实覆盖缺口（例如 `fan` 2.5→4.0 A）；这是需要制定运行期策略解决的问题，不是纯指标假象。

### 2.3 混淆矩阵（用于门控而非纯精度）
- `bad = (state != IDENT_DONE) || (lq <= 0) || (SwpL% > 15.0%) || (|Rs%| > 15.0%)`。
  - **注意（v2.1 澄清）**：`bad` 的分母是全部 N 台；`SwpL` 与 `|Rs|` 两种失败模式在 FN 内必须分开列出（历史报告中 `FN=11` 曾把 5 例 RunL（旧口径）与 6 例 |Rs|>15% 混在一起，与 p95 表面矛盾——按 SwpL 口径其中仅 1 例 SwpL>15%，其余为 |Rs| 静默失败，已由死区过渡带边界修复）。
- `TP/FN/FP/TN` 同 v1；另单列“`SwpL>25%` 且未拦截样本数”（高危静默失败）。
- 运行期外推缺口另外汇总，不用于掩盖 `SwpL` 或 `Rs` 静默失败。

## 3. 扰动验收标准（v2 修订）

传感器误差构成物理下限，扰动实验主要检验：
1. **误差不被异常放大**；
2. **不把传感器扰动误判为转子运动**；
3. **必要时安全阻断而非静默失败**。

| 扰动项 | 参数 | v2 通过标准 |
| --- | --- | --- |
| 电流采样增益 | `SIM_IGAIN=0.95/1.05` | `|Rs%| <= 11%`，`|Lq%| <= 11%`，`SwpL% <= 15%`，`blk=N` |
| 母线采样增益 | `SIM_VBUS_GAIN=0.95/1.05` | 同上 |
| 校准后残余零偏 | `SIM_OFF_RUN=±41 LSB` | `SwpL% <= 15%`；无恒定 DC 零偏引起的 `AC_DRIFT` 误拦；若 `Rs` 因低电流死区拐点超限则须阻断 |
| 死区时间偏差 | `SIM_TD=0.7x/1.3x` | `|Rs%| <= 4%`，`SwpL% <= 12%`，`blk=N` |
| Rs 温漂 | `SIM_R_DRIFT=+0.15` | `SwpL% <= 12%`，`blk=N` |
| 齿槽+静摩擦 | `SIM_COGGING=0.02, SIM_FRIC=0.03` | `|Rs%| <= 4%`，`SwpL% <= 12%`，`blk=N` |
| 对位阻尼网格 | `fan`: `J x {0.1,0.3,1,3,10}` × `psi x {0.5,1,2}` | 15/15 无发散、`blk=N`、`DT_UNSTABLE=0`、`|Rs%| <= 4%`、`SwpL% <= 12%`；另须满足第 5 节颤振判据 |
| 独立 IPM | `ipm2` 同名工况 | 同上（IPM 关注 `Ld/Lq` 与卡滞阻断，不用 SPM 的 d=q 假设） |

**说明**：v2 改用 `SwpL%` 作为主精度指标，是因为 `lsMaxA` 覆盖策略在 v1 时尚未决定；该修改不是删除覆盖问题，`RunL%` 仍需单独报告并验收外推策略。

## 4. `lsMaxA` 覆盖策略的事前评价要求

在盲测前，比较以下策略（不是只按线性饱和选型）：
- `S0`: 扫幅上限处直接钳平（`lsMaxA = 1.0x`）。
- `S1a/S1b/S1c`: 允许运行期有界线性外推到扫幅上限的 `1.3x/1.5x/2.0x`，再钳平。
- `S2`: 矢量/硬件预算允许时抬高辨识梯度顶（优先保证实际覆盖）。
- `S_limit`: 运行期电流限幅不超过已辨识范围（仅作为安全保守对照）。

**评价口径**：分别用线性拐点与渐加速平滑饱和真值，报告 `SwpL%` 与 `RunL%`。提高梯度顶必须重新通过 `IDENT_VEC_PEAK_FITS`、`s_acIpkLim`、`BOARD_HOCP_A` 与 `s_acSatN` 安全校验。

**v2.1 决议与如实记录**：
- 实测数据（线性真值 / 平滑饱和真值下 `RunL` 最坏值）：`1.0x` 钳平 = 22.1% / 15.0%；`1.3x` = 10.7% / 15.3%；`1.5x` = 8.8% / 15.3%；`2.0x` = 8.8% / 15.3%；限流 = 8.8% / 6.9%。
- 按"两种真值最坏情况最小"的纯数据标准，胜出者是**限流**；`1.5x/2.0x/不钳` 在平滑饱和下并列 15.3%。
- **选 `1.5x` 是工程判断而非数据推论**：理由是无实测数据区外推风险随倍数增大，且限流牺牲过载能力。该判断已如实记录。
- **已知限制（写死）**：平滑饱和真值下所有外推策略都卡在约 15%，说明"拐点 + 线性"模型形状对平滑饱和有系统性偏差；真实电机饱和是平滑的，**实机 `RunL` 预期更接近 15% 而非线性真值下的 8.8%**。若实机数据表明需要更优，可调整外推倍数（盲测后再改，不破坏本次冻结）。

## 5. 对位阻尼离散颤振判据

"连续时间无源"不等于"带一阶滤波与采样延迟后无条件稳定"。v2 增加：
- `iqRef` 峰值须受独立于配置的小幅阻尼钳位约束（目标约 `0.1~0.15*MOTOR_I_RATED_A`，不得削弱高磁链电机的有效阻尼）。
- 连续 N 拍指令变号/大幅交替触发颤振检测，并按测量结果减半阻尼；该机制不依赖配置 `psi/J`。
- `vac48` 与 `fan` 上，`J×psi` 网格全程不得出现持续的 500 Hz ±大幅 `iqRef` 交替，定位末端应稳定且满足第 3 节网格标准。

**v2.1 抗噪验证结果**：
- `SIM_NOISE` ×3（=6）下，`fan` 标称 / `J0.1×P0.5` / `J10×P2.0` 三组颤振检测全程 `runD=0`（未触发 Kd 减半），`warn=0x0` —— 噪声不会把健康电机的 Kd 压到下限。
- 强制 `Kd=256`（最坏过度衰减）下 `J10×P2.0` / `J3×P2.0` / `J1×P1.0` 仍全部正常停稳（`warn=0x0`，无 DT_UNSTABLE）—— 减半下限不导致停不稳静默通过。
- 实机颤振场景（`vac48_r21`，ψ=0.42 mWb）：检测在 ~100 ms 内将 Kd 145392→18174 自动收敛，`iqRef` 稳定在 ±70 LSB（~0.017 A）。

## 6. IPD 与已知限制

- 采纳实验结论：保留 C6（IPD 后置），防止低惯量/无凸极 `vac48` 被 IPD 负偏置脉冲击飞。
- **IPD 后置阶段的角色是结果验证与诊断，不再用于 AC 阶段角度输入**：AC 角度仍来自辨识定位角；后置 IPD 通过 `Ipd_Evaluate()` 给出 `gIpd.ok / theta / ratioQ8` 供极性与可信度诊断，不可信时按现有结果可信度门控处理。
- **已知限制**：IPM 被静摩擦/齿槽卡在偏离定位轴 `20°~30°` 时，后置 IPD 方案选择安全阻断而不是保证测准；需要人工核对定位角/机械卡滞，不宣称自动恢复。

## 7. 盲测冻结验收线（运行前写死）

- **种子**：由系统随机数生成（`secrets.randbelow(10**9)`），一次性使用；代码一经修改即作废并重新生成。
- **样本量 N=300**（v2.1 修订）：N=120 时 p95 仅由约 6 个样本支撑，"零失败"在 95% 置信下只能证明 <2.5%；N=300 才能把静默失败率上界压到约 1%。单个种子。
- **每台电机叠加组合扰动**：电流增益 `U[0.95,1.05]`、校准后零偏 `±0.5%FS`（主集；`±2%FS` 单独作为压力子集，只要求不静默失败、允许阻断且阻断不计 FP）、vbus 增益 `U[0.95,1.05]`、死区 `U[0.70,1.30]`、Rs 温漂 `U[0,0.15]`，再叠加电机参数/饱和/额定电流随机化。
- **传感器效应扣除（v2.1 修订）**：`Z=V/I` 使 vbus 增益误差与电流增益误差直接进入 L/R 读数（+5%/-5% 叠加即 10%）。验收线按**扣除已知传感器缩放后的残差**评估：`|SwpL − 已知缩放效应| p95 <= 6%~8%`；绝对值（未扣除）单独报告供参考。
- **健康电机（含组合扰动）**：扣除后残差 `p95 <= 8%`；健康误拦率 `FP <= 3%`（压力子集阻断不计入）。
- **高危静默失败**：`SwpL > 25%` 且未拦截的样本数必须为 **0**。
- **坏电机门控**：独立坏电机集召回率 `TP/(TP+FN) >= 90%`，坏电机误报数据与健康误报分开报告。**v2.1 澄清**：`fan` 平台上的风扰样本在 `[0.08, 0.13) Nm` 区间真值不明（转子可能不动、测得结果常为准确），该区间从混淆矩阵剔除、单独计数（ambiguous），不计入召回率分母。
- **坏样本定义**：`state!=DONE` / `lq<=0` / `SwpL>15%` / `|Rs|>15%`；外推 `RunL` 单列，不借其提高门控召回率。
- **盲测边界（如实声明）**：盲测只能说明在仿真电机分布内未过拟合，**不等于实机通过**；实机顺序为限流电源 + `IDENT_I_SCALE≈0.3` + 已知参数风机 + LCR 表/毫欧表对照。
- **C3 复评**：在最终 `lsMaxA` 策略下，比较保留/去除 3 次谐波 DF 的 `SwpL` 与 `RunL`，按事前阈值重新裁决，不沿用 v1 的混合口径结论。
