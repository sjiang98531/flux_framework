## 1. 固定评估口径（与运行期 `flux_obs.c:lsEff` / `param.c:Param_LqAt` 逐公式一致）

### 1.1 运行期等效电感模型（含 `lsMaxA` 钳位）
对于任意待评估电流 $i > 0$，运行期磁链观测器实际使用的有效电感为：
$$x = \begin{cases} \min(i,\; I_{\text{max,ls}}) & I_{\text{max,ls}} > 0 \\ i & I_{\text{max,ls}} = 0 \end{cases}$$
$$L_{\text{run}}(i) = \begin{cases} L_0 & x \le I_{\text{knee}} \text{ 或 } k \le 0 \\ L_0 \cdot \max\!\left(0.5,\; 1 - k (x - I_{\text{knee}})\right) & \text{否则} \end{cases}$$
- 当辨识未被阻断且参数已提交（`src == 2`）时，$(L_0, I_{\text{knee}}, k, I_{\text{max,ls}})$ 取运行期实际生效的 `(gParam.lqH, gParam.lsKneeA, gParam.lsPerA, gParam.lsMaxA)`；
- 当辨识被阻断（`warn & 0x10`）时，为了评估“若放行会有多大误差”（区分 TP 与 FP），采用 `(gIdent.lqH, gIdent.lsSatKneeA, gIdent.lsSatPerA, lsMax_ident)`（其中若未测得有效 `lqH <= 0` 则误差记 `100%`）。

### 1.2 固定评估电流上限（不随 `s_acSatN` 动态缩小）
- **主口径 `RunL%`**：在固定运行期电流上限（含过载）$I_{\text{run}} = \min(\text{SPD\_PI\_LIMIT},\; I_{\text{MAX}})$ 上均匀采样 200 点，取最大相对误差：
  $$\text{RunL\%} = \max_{i \in (0,\, I_{\text{run}}]} \frac{|L_{\text{run}}(i) - L_{\text{true}}(i)|}{L_{\text{true}}(i)} \times 100\%$$
- **辅助口径 `SwpL%`**：在名义扫幅上限 $I_{\text{swp}} = 2.5 \cdot \text{IDENT\_I\_SCALE}$ 上用同一含 `lsMaxA` 钳位模型计算最大相对误差，用于对照历史数据。

### 1.3 坏样本与混淆矩阵定义
- 样本判为“坏（应拦截）”：`bad = (state != IDENT_DONE) || (lq <= 0) || (RunL% > 15.0%) || (|Rs%| > 15.0%)`。
- 算法拦截判定：`blk = bool(warn & IDENT_WARN_AUTO_BLOCKED)`（`0x10`）。
- 混淆矩阵：`TP`（bad & blk）、`FN`（bad & !blk，静默失败）、`FP`（!bad & blk，误拦）、`TN`（!bad & !blk）。

## 2. 消融保留判据（事前写死，不事后解释）

针对 `75487c4` 相对 `0f98ead` 引入的 6 个独立组件：
- **C1**：无源对位阻尼（`startup.c` 去除未标定 `Rs*iq` 与 `s_dtFilt` 扣除，改 `iq = -Kd * vq_ss` 及 `|vq_filt| + |focKrs*iq|` 判停）
- **C2**：2-DOF 复阻抗前馈 + 保守带宽 PI + 快环瞬时峰值保护 `s_acIpkLim` / 动态截断 `s_acSatN`
- **C3**：含 3 次谐波的精确描述函数（`s_acH3s/c` 解调 + `dfStep` 非正弦波形积分）
- **C4**：R/L 粗测感抗相位角 `< ~8.5°` 自动切高频复测（`s_rlPass`）
- **C5**：死区阶梯 20 ms 子窗 + 拟合残差校验 + 交流零偏置段整周期正交轴静止监测 + 去模型摆动上界 `0.35·L0·ω0²`
- **C6**：阶段重排（IPD 后移至 AC/SAT_FIT 之后）

在**困难集**（`20261119` N=120 + 旧 6 个 FN `20261118` `rand_01/06/21/33/55/81` + `vac48_offgn_30x` + 扰动集 + 坏电机门控集）上执行**双向消融**（`75487c4 - Ci` 与 `0f98ead + Ci`）。

**组件 `Ci` 仅在满足以下至少一条时保留，否则拆除**：
1. **精度/静默失败改善**：在固定 `RunL%` 口径下，使困难集 `RunL%` 的 p95 或 max 改善 **≥ 1.5 个百分点**，或减少静默失败 `FN` 至少 **1 例**且不使健康集 `FP` 率升高超过 **2.0%**；或
2. **修复明确物理失效**：修复至少 1 项具名物理失败工况（例如 `wrong_fan_psi_hi` `|Rs%|` 从 >5% 降至 ≤2.5%、0.02 Nm 微风扰动从漏放变为拦截、极低电感相位不足从失败变为收敛）；或
3. **硬性安全必需**：属于防止硬件过流/失控/参数混用的安全机制（如瞬时峰值硬保护 `s_acIpkLim`、防旧 `lsPerA` 混用的 `s_l0Only` 门控）。

## 3. 硬件与物理扰动验收标准（事前写死）

传感器标定误差本身构成物理下限，不要求算法突破物理极限，但**禁止放大误差或误拦**：

| 扰动项 | 测试参数 | 通过标准 |
| --- | --- | --- |
| 电流采样增益误差 | `SIM_IGAIN = 0.95, 1.05`（±5%） | `|Rs%| ≤ 11%`、`|Lq%| ≤ 11%`、`RunL% ≤ 15%`（传感器误差 + 6% 余量），`blk = N` |
| 母线采样增益误差 | `SIM_VBUS_GAIN = 0.95, 1.05`（±5%） | `|Rs%| ≤ 11%`、`|Lq%| ≤ 11%`、`RunL% ≤ 15%`，`blk = N` |
| 校准后残余电流零偏 | `SIM_OFF_RUN = ±41` LSB（±2% FS，在 `ZeroOffset` 后注入） | `|Rs%| ≤ 4%`、`RunL% ≤ 12%`，`blk = N` |
| 死区时间偏差 | `SIM_TD = 0.7×, 1.3×` 标称值（±30%） | `|Rs%| ≤ 4%`、`RunL% ≤ 12%`，`blk = N` |
| 电阻温漂（DT→AC 漂移） | `SIM_R_DRIFT = +0.15`（阶梯到交流期间 Rs 升高 15%） | `RunL% ≤ 12%`（电感虚部不受 Rs 漂移影响），`blk = N` |
| 齿槽转矩 + 静摩擦 | `SIM_COGGING = 0.02 Nm, SIM_FRIC = 0.03 Nm` | `|Rs%| ≤ 4%`、`RunL% ≤ 12%`，`blk = N` |
| 对位阻尼稳定性网格 | `fan` 上 `J × {0.1, 0.3, 1, 3, 10}` × `ψ × {0.5, 1, 2}`（15 组） | 15/15 稳定收敛无振荡，`|Rs%| ≤ 4%`、`RunL% ≤ 12%`，`DT_UNSTABLE = 0`，`blk = N` |

## 4. “应拦”坏电机门控验证集（确保 `TP + FN > 0`）

包含两类坏电机样本，用于真正检验门控召回率：
1. **具名坏工况（10 项）**：断相（`Rs=50 kΩ`）、极低电感低信噪比（`vac16 L=2 μH, Td=2.5 μs`）、极低母线（`fan Vbus=35 V`）、风车带转（`fan 0.02 / 0.08 / 0.15 Nm`）、极端深度饱和（`fan qSat=0.42`, `sm120 qSat=0.075`, `vac48 qSat=0.045`）、额定电流错填 0.25×/3.0× 饱和电机。
2. **随机坏电机压力批（`seed = 20261188`，N=30）**：在物理不可辨识或强过载饱和区抽样（高饱和斜率、低 SNR、大死区、大额定电流失配），使 `TP + FN ≥ 10`。

## 5. IPD 专项对比实验（消融之后执行）

在以下三类关键转子角场景对比三种方案（`IPD 在前`、`IPD 在后`、`IPD 在前 + 复用 |vq|+|R*iq| 短稳停后进 AC`）：
1. 初始电角度在 `180° ± 5°`（`175°, 178°, 180°, 182°, 185°`）的 SPM（`fan`）与 IPM（`ipm2`）— 检验反极性卡滞风险；
2. 静摩擦导致对位后转子被卡在偏离 `alignDeg` 20° / 30° 处的 SPM（`fan`）与 IPM（`ipm2`）— 检验 d/q 混叠；
3. 低惯量电机（`fan` `J × 0.1 / 0.2`）— 检验 IPD 负偏置脉冲是否击飞转子。
